# Evidence register

Use one row per claim or datum that may support the analysis. Keep observations
distinct from problem assessments and recommendations. Cite the source locator
precisely enough for another reader to find the evidence.

| Evidence ID | Source ID | Source locator | Statement | Type | Period / population / unit | Caveat or comparability note |
|---|---|---|---|---|---|---|
| | | | | DATA / CALCULATION / INTERPRETATION | | |

## Recording rules

- DATA must faithfully represent a source and include a report locator.
- CALCULATION must identify its input evidence IDs, formula, and working.
- INTERPRETATION must identify the evidence IDs it relies on and state
  uncertainty or plausible alternatives.
- Keep conflicting values as separate records until their definitions,
  periods, and methods have been compared.
- A blank or unreported item is a data gap, not evidence that the underlying
  condition is absent.
